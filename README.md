# Present for Ira - Wallet 🚀

A sleek, premium personal wallet and goal tracker application.

## Features

- 🎯 **Goal Tracking:** Set a target amount and a target date.
- 💸 **Funds Management:** Easily add your current earnings.
- 📊 **Dashboard:** View progress percentage, remaining balance, and required daily average.
- 🎨 **Premium UI/UX:** Built using an elegant design system (dark theme with signal-lime accents).

## Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- Lucide React
- date-fns

## Deployment

Deploy this project on [Vercel](https://vercel.com/) with a single click.

1. Push your repository to GitHub.
2. Go to Vercel, import your project.
3. Keep the default settings and deploy.
